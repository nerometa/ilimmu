# Ilimmu design

The [design guide](../DESIGN.md) defines Ilimmu's colors, typography,
components, and responsive layouts. The [task flows](ux-flows.md) describe
navigation, editing, and recovery states.

The design is ahead of the running app in some areas. Overview, the combined
Inventory navigation, and the revised component library describe the intended
interface. They aren't a claim that those changes are implemented.

Design exports, board IDs, review notes, and connection logs belong in the
private `.local/` directory.
